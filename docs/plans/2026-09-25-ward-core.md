# Ward core — Implementation Plan (Plan 1 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Ward's reusable entry workflow (`ci.yml`) with the identity, node and dotnet modules, the single `gate` check, Dependabot auto-merge, the baseline templates, and Ward's own CI dogfooding all of it.

**Architecture:** `ci.yml` is one reusable workflow whose jobs are the modules; each job checks out Ward's own `tools/` at `job.workflow_sha` into `$RUNNER_TEMP/ward` and runs a dependency-free Node script there, so logic is unit-tested and always matches the workflow version. `gate` needs every module and is the one required check (`ward / gate`). Auto-merge is a separate reusable workflow the caller invokes from a second job pinned to a full SHA.

**Tech Stack:** GitHub Actions (reusable workflows), Node 24 ESM scripts using only the standard library, `node:test`, Biome 2.5.14, .NET SDK 10 for the dotnet fixtures.

**Spec:** `docs/specs/2026-09-25-ci-standard-design.md`

## Global Constraints

- Node **24** in every workflow and as the local floor; scripts use the Node standard library only — no runtime dependencies.
- .NET SDK **10.0.x** (local 10.0.401); `dotnet-ef` **10.0.12**.
- Biome **2.5.14**, pinned exactly in `package.json`.
- Every `uses:` of a third-party or GitHub action is pinned to a full 40-character commit SHA with a version comment. SHAs verified 2026-09-25:
  - `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1`
  - `actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0`
  - `actions/setup-dotnet@a98b56852c35b8e3190ac28c8c2271da59106c68 # v6.0.0`
  - `dependabot/fetch-metadata@25dd0e34f4fe68f24cc83900b1fe3fe149efef98 # v3.1.0`
- Workflows use `pull_request` and `push`, never `pull_request_target`. Default `permissions: contents: read`; only the auto-merge job gets write.
- Values from caller inputs and event payloads reach `run:` only through `env:`, never inline `${{ }}` in a script.
- Required check name: **`ward / gate`**. Commit author: `malinfossum.dev@proton.me`. No `Co-Authored-By`, no AI attribution in commits or PRs.
- English everywhere; README and docs in first person.
- Work on branch `feat/core` off `main`; one PR; merging, tagging and releasing are Malin's calls.

## Deviations from the spec (recorded in Task 9)

1. Modules are **jobs inside `ci.yml`**, not separate reusable workflow files. GitHub does not document how `./` paths resolve in nested reusable workflows called cross-repo; one flat workflow avoids the question. Check names become `ward / identity`, `ward / node`, `ward / dotnet`, `ward / gate`.
2. `dotnet-ef: true` becomes `dotnet-ef-project: <path>` (+ optional `dotnet-ef-startup-project`), because the EF command needs a project path.
3. `stacks.json` arrives with Plan 3 (its first consumer is the skill); the node contract's detection lives in `tools/node-contract.mjs` until then.

`tools/identity.mjs`:
```js
// Every commit in a range must be authored by an allowed address and carry no
// AI attribution. The identity job in ci.yml runs this.
import { execFileSync } from "node:child_process";
import { pathToFileURL } from "node:url";

export const DEPENDABOT = "49699333+dependabot[bot]@users.noreply.github.com";
export const GITHUB_WEB = "noreply@github.com";

const ATTRIBUTION = /^claude-session:|generated with .*(claude|copilot|chatgpt|cursor)/i;
const AI_COAUTHOR = /claude|anthropic|copilot|openai|chatgpt|cursor|\[bot\]/i;

export function parseAllowed(value) {
  return value
    .split(/[\s,]+/)
    .map((address) => address.trim().toLowerCase())
    .filter(Boolean);
}

export function parseLog(raw) {
  return raw
    .split("\x1e")
    .map((record) => record.replace(/^\s+/, ""))
    .filter(Boolean)
    .map((record) => {
      const [sha, author, committer, subject, body = ""] = record.split("\x1f");
      return { sha, author, committer, subject, body };
    });
}

export function textProblems(text, { allowHumanCoauthors }) {
  const problems = [];
  for (const raw of text.split(/\r?\n/)) {
    const line = raw.trim();
    if (ATTRIBUTION.test(line)) {
      problems.push(`attribution line: ${line}`);
    } else if (
      /^co-authored-by:/i.test(line) &&
      (!allowHumanCoauthors || AI_COAUTHOR.test(line))
    ) {
      problems.push(`co-author line: ${line}`);
    }
  }
  return problems;
}

export function commitProblems(commit, policy) {
  const authors = new Set([...policy.allowed, DEPENDABOT]);
  const committers = new Set([...policy.allowed, DEPENDABOT, GITHUB_WEB]);
  const problems = [];
  if (!authors.has(commit.author.toLowerCase())) {
    problems.push(`authored by <${commit.author}>`);
  }
  if (!committers.has(commit.committer.toLowerCase())) {
    problems.push(`committed by <${commit.committer}>`);
  }
  problems.push(...textProblems(commit.body, policy));
  return problems;
}

function main() {
  const env = process.env;
  const policy = {
    allowed: parseAllowed(env.ALLOWED ?? ""),
    allowHumanCoauthors: env.ALLOW_HUMAN_COAUTHORS === "true",
  };
  const head = env.HEAD || "HEAD";
  const range = /^0*$/.test(env.BASE ?? "") ? ["-1", head] : [`${env.BASE}..${head}`];
  const raw = execFileSync(
    "git",
    ["log", "--format=%H%x1f%ae%x1f%ce%x1f%s%x1f%B%x1e", ...range],
    { encoding: "utf8" },
  );

  let bad = 0;
  for (const commit of parseLog(raw)) {
    for (const problem of commitProblems(commit, policy)) {
      console.log(`::error::${commit.sha.slice(0, 7)} ${problem} (${commit.subject})`);
      bad++;
    }
  }
  for (const problem of textProblems(`${env.PR_TITLE ?? ""}\n${env.PR_BODY ?? ""}`, policy)) {
    console.log(`::error::Pull request ${problem}`);
    bad++;
  }
  if (bad === 0) {
    console.log("Every commit is authored by an allowed address and carries no AI attribution.");
  }
  process.exitCode = bad ? 1 : 0;
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) main();
```

```js
// Runs the npm script contract for the node module. Which scripts are required
// depends on what the repo contains.
import { spawnSync } from "node:child_process";
import { readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { pathToFileURL } from "node:url";

const MODES = new Set(["off", "warn", "strict"]);

export function planSteps({ scripts, files, a11y, hasPlaywright }) {
  if (!MODES.has(a11y)) throw new Error(`a11y must be off, warn or strict, got "${a11y}"`);
  const has = (name) => Object.hasOwn(scripts, name);
  const typed = files.includes("tsconfig.json") || files.some((f) => /^astro\.config\./.test(f));
  const worker = files.some((f) => /^wrangler\.(toml|json|jsonc)$/.test(f));

  const contract = [
    { script: "lint", required: true },
    { script: "typecheck", required: typed },
    { script: "test", required: true },
    { script: "build", required: false },
    { script: "deploy:check", required: worker },
    { script: "test:e2e", required: a11y !== "off", soft: a11y === "warn", skip: a11y === "off" },
  ];

  const missing = contract.filter((c) => c.required && !has(c.script)).map((c) => c.script);
  const steps = [];
  for (const c of contract) {
    if (c.skip || !has(c.script)) continue;
    if (c.script === "test:e2e" && hasPlaywright) {
      steps.push({
        name: "playwright browsers",
        cmd: "npx playwright install --with-deps --only-shell chromium",
        soft: false,
      });
    }
    steps.push({ name: c.script, cmd: `npm run ${c.script}`, soft: Boolean(c.soft) });
  }
  return { steps, missing };
}

function main() {
  const dir = process.argv[2] ?? ".";
  const pkg = JSON.parse(readFileSync(join(dir, "package.json"), "utf8"));
  const deps = { ...pkg.dependencies, ...pkg.devDependencies };
  const { steps, missing } = planSteps({
    scripts: pkg.scripts ?? {},
    files: readdirSync(dir),
    a11y: process.env.A11Y ?? "off",
    hasPlaywright: "@playwright/test" in deps,
  });

  let failed = 0;
  for (const script of missing) {
    console.log(`::error::package.json has no "${script}" script, which this repo needs`);
    failed++;
  }
  for (const step of steps) {
    console.log(`::group::${step.name}`);
    const { status } = spawnSync(step.cmd, { cwd: dir, stdio: "inherit", shell: true });
    console.log("::endgroup::");
    if (status === 0) continue;
    if (step.soft) {
      console.log(`::warning::${step.name} failed (a11y is in warn mode)`);
    } else {
      console.log(`::error::${step.name} failed`);
      failed++;
    }
  }
  process.exitCode = failed ? 1 : 0;
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) main();
```

```js
// Restore, build with warnings as errors, verify formatting, test, and
// optionally check for EF Core model changes without a migration.
import { spawnSync } from "node:child_process";
import { pathToFileURL } from "node:url";

export function planDotnet({ efProject = "", efStartupProject = "" } = {}) {
  const steps = [
    { name: "restore", cmd: "dotnet restore" },
    { name: "build", cmd: "dotnet build --no-restore -warnaserror" },
    { name: "format", cmd: "dotnet format --verify-no-changes --no-restore" },
    { name: "test", cmd: "dotnet test --no-build" },
  ];
  if (efProject) {
    const startup = efStartupProject || efProject;
    steps.push({
      name: "pending migrations",
      cmd: `dotnet ef migrations has-pending-model-changes --no-build --project "${efProject}" --startup-project "${startup}"`,
    });
  }
  return steps;
}

function main() {
  const dir = process.argv[2] ?? ".";
  const steps = planDotnet({
    efProject: process.env.EF_PROJECT ?? "",
    efStartupProject: process.env.EF_STARTUP_PROJECT ?? "",
  });
  for (const step of steps) {
    console.log(`::group::${step.name}`);
    const { status } = spawnSync(step.cmd, { cwd: dir, stdio: "inherit", shell: true });
```

`tools/automerge.mjs`:
```js
// Decides whether a Dependabot PR may auto-merge: patch or minor only, nothing
// bound to the .NET runtime, and only where the default branch requires Ward's
// gate. Without a required check, auto-merge would merge instantly.
import { execFileSync } from "node:child_process";
import { pathToFileURL } from "node:url";

export const RUNTIME_BOUND = [
  /^Microsoft\.AspNetCore\./i,
  /^Microsoft\.EntityFrameworkCore/i,
  /^Microsoft\.Extensions\./i,
  /^Microsoft\.NET(Core)?\./i,
  /^System\./i,
  /^dotnet-sdk$/i,
  /\/dotnet\//i,
];

const SAFE = new Set(["version-update:semver-patch", "version-update:semver-minor"]);

export function requiredChecksFrom(rules) {
  return rules
    .filter((rule) => rule.type === "required_status_checks")
    .flatMap((rule) => rule.parameters.required_status_checks.map((check) => check.context));
}

export function decide({ updateType, dependencies, requiredChecks, requiredCheck }) {
  if (!requiredChecks.includes(requiredCheck)) {
    return { merge: false, reason: `the default branch does not require "${requiredCheck}"` };
  }
  if (!SAFE.has(updateType)) {
    return { merge: false, reason: `${updateType || "an unknown update type"} needs my review` };
  }
  const bound = dependencies.filter((name) => RUNTIME_BOUND.some((pattern) => pattern.test(name)));
  if (bound.length) {
    return { merge: false, reason: `runtime-bound: ${bound.join(", ")}` };
  }
  return { merge: true, reason: `${updateType} of ${dependencies.join(", ")}` };
}

function main() {
  const env = process.env;
  const rules = JSON.parse(
    execFileSync("gh", ["api", `repos/${env.REPO}/rules/branches/${env.BRANCH}`], {
      encoding: "utf8",
    }),
  );
  const result = decide({
    updateType: env.UPDATE_TYPE ?? "",
    dependencies: (env.DEPENDENCIES ?? "").split(",").map((d) => d.trim()).filter(Boolean),
    requiredChecks: requiredChecksFrom(rules),
    requiredCheck: env.REQUIRED_CHECK,
  });
  if (!result.merge) {
    console.log(`::notice::Leaving this PR for review: ${result.reason}`);
    return;
  }
  execFileSync("gh", ["pr", "merge", "--auto", "--squash", env.PR_URL], { stdio: "inherit" });
  console.log(`Auto-merge enabled: ${result.reason}`);
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) main();
```

````markdown
# Ward

Shared CI, security and accessibility checks for all my repos.

Every repo of mine calls one workflow here. It runs the checks that fit the repo's stack and reports a
single required check, `ward / gate`, so a red check always blocks a merge.

## Stack

GitHub Actions reusable workflows, Node 24 scripts with no dependencies, `node:test`, Biome.

## Use it

Copy [`templates/ward.yml`](templates/ward.yml) to `.github/workflows/ward.yml` and set the inputs:

```yaml
jobs:
  ward:
    uses: malinfossum/ward/.github/workflows/ci.yml@v1
    with:
      node: "."
      dotnet: ""
```

| Module | Runs | Input |
|---|---|---|
| identity | Every commit is mine or Dependabot's and carries no AI attribution | always on |
| node | `lint`, `typecheck`, `test`, `build`, `deploy:check`, `test:e2e` from `package.json` | `node` |
| dotnet | Restore, build with warnings as errors, `dotnet format`, test, EF pending-model check | `dotnet`, `dotnet-ef-project` |

The baseline also covers Dependabot with patch and minor auto-merge, secret scanning with push
protection, CodeQL, and a ruleset on `main`. The full standard is in
[the design spec](docs/specs/2026-09-25-ci-standard-design.md).

## Develop

```bash
npm install
npm test               # unit tests
npm run test:fixtures  # scripts against good and broken fixtures (needs the .NET 10 SDK)
npm run lint
```

## Layout

| Path | What |
|---|---|
| `.github/workflows/` | `ci.yml` (entry point), `dependabot-automerge.yml`, Ward's own `ward.yml` |
| `tools/` | The scripts each job runs, with their unit tests |
| `templates/` | What a repo copies: caller, Dependabot config, rulesets, `Directory.Build.props` |
| `fixtures/`, `tests/` | Known-good and known-broken projects and the tests that run them |
````
